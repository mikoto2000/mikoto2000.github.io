大きい CSV を扱うとき

CSV はローカルファイルから部分読み込みし、登録時には全行を取り込みません。登録・プレビューが成功しても、全行の解析が成功したとは限りません。行数や集計で確認してください。複数 CSV の合計サイズ、列数、ソート・JOIN の内容、端末のメモリにより処理可能な量は変わります。

数値中心の 1 GB CSV を想定した PC 向けです。メモリ不足の場合は、対象列や条件を絞ってください。このページではディスクへの一時退避は使いません。型推定で後半の値に合わない場合は、すべて文字列として登録し直して CAST / TRY_CAST を使えます。

通信と数値の扱い

SQL エンジン・WASM・画面をこの HTML に同梱しています。初回の HTML 取得以降、CSV の登録・SQL 実行・結果保存による HTTP/HTTPS 通信はありません。広告・外部フォント・アクセス解析は使いません。URL を SQL へ指定してデータを取得する機能や、拡張の追加ダウンロードも無効です。トップページへの移動や再読み込みは別のページ取得になります。

BIGINT・DECIMAL の結果は DuckDB 内で文字列に変換し、JavaScript の数値変換による桁落ちを避けます。CSV の小数が DOUBLE と推定された場合は浮動小数点演算になります。金額などの厳密な計算では DECIMAL への明示的な CAST を指定してください。CSV 保存は表示中の最大 1,000 行のみで、NULL は空欄になります。表計算ソフトで開く際は、文字列が数式として解釈される場合があります。
